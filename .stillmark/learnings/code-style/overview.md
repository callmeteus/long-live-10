# Code style learnings

Stable coding conventions for this repo. Add more `.md` files in this folder (one concern per file), like Cursor rules.

## Commits

Stillmark checks recent `git log` for conventional commits (`docs:` / `chore:` for its own commits, never copying scopes) unless `git.commitMessage` is set in `stillmark.config.json`. Preview with `stillmark git message-style`.

## How to use

- Record naming, formatting, test habits, and review notes the agent should reuse.
- Prefer examples over abstract rules.
